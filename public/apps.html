Change multiple file extensions in Windows 11

Extension Changer is designed for bulk file extension changes when renaming files one at a time would be tedious. Use it to change an existing extension, or add an extension to files that are missing one. The utility renames filenames only. It does not convert the underlying file format.

Portable app downloads

The Windows utility is intended to be portable, so the EXE can be run without a traditional installer. Download links on this page can be changed to the latest GitHub Release whenever a new version becomes available.

Questions about the downloads

Is Extension Changer free?

Yes. It is intended as a free utility with optional support from users who find it helpful.

Does it convert file formats?

No. Extension Changer changes the filename extension. It does not transcode or convert the file's contents.
